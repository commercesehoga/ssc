# SSC Dashboard — Exam & Subject ID Reference

## 🔑 localStorage Result Key Format

```
thunderstudy_result_{SUBJECT_ID}_{CHAPTER_ID}
```

**Example:**
```js
const SUBJECT_ID = "cgl";   // exam id
const CHAPTER_ID = "eng6";  // mock id
// saves to → thunderstudy_result_cgl_eng6
```

## 🔐 Name Auto-fetch Keys (SSC Platform)

The dashboard stores user identity across these localStorage keys in priority order:

```
ssc_profile  →  .name field (JSON object)
ssc_name     →  plain string
cbtUserName  →  plain string
ts_profile   →  .name field (JSON object)

ts_student_id    →  student ID (priority 1)
ssc_student_id   →  student ID (priority 2)
```

Use these helper functions in every CBT file:

```js
function sscGetName() {
  try { const p = JSON.parse(localStorage.getItem('ssc_profile') || '{}'); if (p.name) return p.name; } catch(e) {}
  return localStorage.getItem('ssc_name')
      || localStorage.getItem('cbtUserName')
      || (() => { try { return JSON.parse(localStorage.getItem('ts_profile') || '{}').name || ''; } catch { return ''; } })()
      || '';
}

function sscGetID() {
  return localStorage.getItem('ts_student_id')
      || localStorage.getItem('ssc_student_id')
      || '';
}

function sscSaveName(n) {
  if (!n) return;
  localStorage.setItem('cbtUserName', n);
  localStorage.setItem('ssc_name', n);
  try { const p = JSON.parse(localStorage.getItem('ssc_profile') || '{}'); if (!p.name) { p.name = n; localStorage.setItem('ssc_profile', JSON.stringify(p)); } } catch(e) {}
}
```
